01. Tech Stack & Prinsip Arsitektur

Daftar pustaka inti yang dipilih karena kecepatan, stabilitas, dan ketiadaan dependensi backend.

Komponen Teknologi Terpilih Peran & Alasan Pemilihan
UI Framework React 19 + TypeScript Type safety penuh, ekosistem kaya, dan rendering state reaktif yang cepat.
Bundler & Dev Server Vite 8 Build secepat kilat (< 1 detik), Hot Module Replacement (HMR) instan, bundling ringan.
Styling System Tailwind CSS Desain utilitas konsisten, mudah dipadukan dengan iOS Design Tokens & Dark/Light mode.
Ikonografi Lucide React Koleksi ikon SVG outline konsisten, ringan, dan cocok dengan gaya native iOS.
Penyimpanan Lokal IndexedDB (via library idb) Kapasitas penyimpanan besar (>50MB), terstruktur, tidak terhapus saat refresh browser.
Feedback Haptik & Audio Web Audio API + Vibrate API Klik sintetis instan tanpa beban file audio besar; fallback haptik otomatis di iOS Safari.
Pengujian Unit Vitest Unit testing cepat tanpa konfigurasi berat, kompatibel 100% dengan syntax Jest.

Prinsip Desain Utama:

  • ✓ 100% Offline-First: Semua fitur utama wajib berfungsi sempurna tanpa internet setelah instalasi awal.
  • ✓ Tanpa Backend / Tanpa Login: Pengguna dapat langsung menggunakan aplikasi dalam 1 detik tanpa registrasi.
  • ✓ One-Hand Thumb Zone: Tombol aksi utama ditempatkan di area bawah layar yang mudah dijangkau jempol.
  • ✓ Zero Double-Tap Zoom: Memakai touch-action: manipulation untuk mematikan zoom double tap iOS yang mengganggu.

Template public/sw.js (Cache-First + External Fonts Caching):

public/sw.js 
const CACHE_NAME = 'app-cache-v1';
const ASSETS_TO_CACHE = [
  './',
  './index.html',
  './manifest.webmanifest',
  './icons/icon.svg',
  './icons/icon-192.png',
  './icons/icon-512.png',
];

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => {
      return cache.addAll(ASSETS_TO_CACHE).catch((err) => {
        console.warn('Precache warning:', err);
      });
    })
  );
  self.skipWaiting();
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((keys) => {
      return Promise.all(
        keys.filter((key) => key !== CACHE_NAME).map((key) => caches.delete(key))
      );
    })
  );
  self.clients.claim();
});

self.addEventListener('fetch', (event) => {
  if (event.request.method !== 'GET') return;

  const url = new URL(event.request.url);

  // Navigasi HTML: coba network dahulu, fallback ke cached index.html
  if (event.request.mode === 'navigate') {
    event.respondWith(
      fetch(event.request).catch(() => {
        return caches.match('./index.html') || caches.match('./') || caches.match(self.registration.scope);
      })
    );
    return;
  }

  // Cache aset lokal + font eksternal (Google Fonts)
  const isGoogleFont = url.origin === 'https://fonts.googleapis.com' || url.origin === 'https://fonts.gstatic.com';

  if (url.origin === self.location.origin || isGoogleFont) {
    event.respondWith(
      caches.match(event.request).then((cachedResponse) => {
        if (cachedResponse) {
          // Update cache di background jika online
          fetch(event.request)
            .then((networkResponse) => {
              if (networkResponse && (networkResponse.status === 200 || networkResponse.type === 'opaque')) {
                const responseToCache = networkResponse.clone();
                caches.open(CACHE_NAME).then((cache) => {
                  cache.put(event.request, responseToCache);
                });
              }
            })
            .catch(() => {});
          return cachedResponse;
        }

        return fetch(event.request)
          .then((networkResponse) => {
            if (!networkResponse || (networkResponse.status !== 200 && networkResponse.type !== 'opaque')) {
              return networkResponse;
            }
            const responseToCache = networkResponse.clone();
            caches.open(CACHE_NAME).then((cache) => {
              cache.put(event.request, responseToCache);
            });
            return networkResponse;
          })
          .catch(() => caches.match(event.request));
      })
    );
  }
});

2. Audio Feedback Sintetis (Web Audio API):

iOS Safari sering menolak getaran navigator.vibrate(). Sebagai gantinya, gunakan Web Audio API sintetis untuk menghasilkan suara klik lembut instan tanpa lag:

src/lib/haptics.ts 
// Audio klik sintetis (kompatibel penuh dengan iOS Safari)
export const playClickSound = () => {
  try {
    const AudioCtx = window.AudioContext || (window as unknown as { webkitAudioContext: typeof AudioContext }).webkitAudioContext;
    if (!AudioCtx) return;

    const ctx = new AudioCtx();
    const osc = ctx.createOscillator();
    const gain = ctx.createGain();

    osc.type = 'sine';
    osc.frequency.setValueAtTime(800, ctx.currentTime);
    osc.frequency.exponentialRampToValueAtTime(300, ctx.currentTime + 0.04);

    gain.gain.setValueAtTime(0.12, ctx.currentTime);
    gain.gain.exponentialRampToValueAtTime(0.01, ctx.currentTime + 0.04);

    osc.connect(gain);
    gain.connect(ctx.destination);

    osc.start();
    osc.stop(ctx.currentTime + 0.04);
  } catch {
    // Ignore audio errors jika perangkat mute
  }
};

// Haptic vibration (Android & browser yang mendukung)
export const triggerHaptic = (durationMs = 15) => {
  if ('vibrate' in navigator) {
    try {
      navigator.vibrate(durationMs);
    } catch {}
  }
};

05. Penyimpanan Data Lokal (IndexedDB)

Pola implementasi penyimpanan lokal persisten dengan IndexedDB menggunakan pustaka idb.

src/lib/database.ts 
import { openDB, DBSchema, IDBPDatabase } from 'idb';

interface AppDB extends DBSchema {
  items: {
    key: string;
    value: {
      id: string;
      title: string;
      createdAt: string;
      updatedAt: string;
    };
  };
  settings: {
    key: string;
    value: {
      id: string;
      soundEnabled: boolean;
      hapticsEnabled: boolean;
      theme: string;
    };
  };
}

const DB_NAME = 'MyMobileAppDB';
const DB_VERSION = 1;

let dbPromise: Promise<IDBPDatabase<AppDB>> | null = null;

export const getDB = (): Promise<IDBPDatabase<AppDB>> => {
  if (!dbPromise) {
    dbPromise = openDB<AppDB>(DB_NAME, DB_VERSION, {
      upgrade(db) {
        if (!db.objectStoreNames.contains('items')) {
          db.createObjectStore('items', { keyPath: 'id' });
        }
        if (!db.objectStoreNames.contains('settings')) {
          db.createObjectStore('settings', { keyPath: 'id' });
        }
      },
    });
  }
  return dbPromise;
};

// Ekspor & Impor Cadangan Data (JSON)
export const exportDataAsJSON = async () => {
  const db = await getDB();
  const items = await db.getAll('items');
  const settings = await db.get('settings', 'app-settings');

  const backup = {
    appName: 'MyMobileApp',
    exportedAt: new Date().toISOString(),
    data: { items, settings },
  };

  const blob = new Blob([JSON.stringify(backup, null, 2)], { type: 'application/json' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `backup-${new Date().toISOString().slice(0, 10)}.json`;
  a.click();
  URL.revokeObjectURL(url);
};

06. Alur Deployment Otomatis ke GitHub Pages

Cara merilis aplikasi ke GitHub Pages dengan dukungan HTTPS resmi dan branch gh-pages.

  1. Inisialisasi Git Lokal: 
    git init -b main
git add .
git commit -m "feat: Inisialisasi awal proyek mobile app"
  2. Hubungkan ke Repository GitHub: 
    git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
  3. Build & Deploy ke branch gh-pages: 
    npm run build
cd dist
git init -b gh-pages
git add -A
git commit -m "deploy: Release GitHub Pages"
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -f origin gh-pages
  4. Aktifkan GitHub Pages di Web: Buka https://github.com/USERNAME/REPO-NAME/settings/pages ➔ Pilih Source: Deploy from a branch ➔ Branch: gh-pages / /(root) ➔ Klik Save.
